Relatório Técnico: predictor.py
1. Visão Geral
O arquivo predictor.py implementa o serviço de Machine Learning do projeto EUFit, responsável por:

Treinar modelos de regressão linear baseados no histórico do usuário

Prever métricas corporais faltantes (músculo, idade, basal) a partir de dados conhecidos (peso, gordura, visceral)

Atualizar registros no banco de dados com as predições

Executar predições em memória (on-the-fly) durante o preenchimento de formulários

2.3 Método: train_models()

def train_models(self):
    X_cols = ['peso', 'gordura', 'viceral']
    y_cols = ['musculo', 'idade', 'basal']
    
    training_df = self.df_ml_data[X_cols + y_cols].dropna()
    X = training_df[X_cols]
    
    for target in y_cols:
        model = LinearRegression()
        model.fit(X, training_df[target])
        self.trained_models[target] = model
Propósito: Treinar três modelos de regressão linear independentes.

Variáveis:

Tipo	Colunas	Descrição
X (Features)	peso, gordura, viceral	Dados de entrada obrigatórios
Y (Targets)	musculo, idade, basal	Métricas a serem previstas
Comportamento:

Remove registros com valores nulos (dropna())

Treina um modelo para cada métrica alvo

Armazena modelos em self.trained_models

Retorna True se treinado com sucesso

    # Trava de segurança: exige ao menos 5 registros
    if len(self.df_ml_data) < 5:

    # Predição em memória (sem tocar no banco)

        predictions[target] = round(max(0.0, float(pred)), 2)

Propósito: Prever métricas em tempo real durante o preenchimento do formulário, sem persistir no banco.

Características:

Cold Start Protection: Exige pelo menos 5 registros históricos

Clipping: Impede valores negativos (max(0.0, pred))

Idade: Arredondada para inteiro

Retorno: Dicionário com musculo, idade, basal

4. Validações de Segurança
Validação	Método	Propósito
Isolamento por user_id	Todos	Impede que um usuário veja dados de outro
Mínimo de registros	predict_on_the_fly	Evita predições com dados insuficientes (< 5)
Sobrescrita de dados	predict_and_update_db_record	Não sobrescreve dados preenchidos manualmente
Clipping (max 0.0)	predict_on_the_fly	Impede valores negativos em métricas corporais
Dropna	train_models	Remove registros com dados nulos antes do treino

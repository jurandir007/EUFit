Módulo Vape - Documentação
Visão Geral
O Módulo Vape é uma funcionalidade paralela ao sistema principal de métricas corporais do EUFit. Permite o registro e monitoramento do consumo diário de vape (cigarros eletrônicos) através de uma interface dedicada, com gráficos de evolução, médias móveis e previsões baseadas em regressão linear.

Modelo de Dados
python
class RecordVape(db.Model):
    __tablename__ = 'record_vape'
    id = db.Column(db.Integer, primary_key=True)
    user_id = db.Column(db.Integer, db.ForeignKey('users.id'), nullable=False)
    puff_count = db.Column(db.Integer, nullable=False)
    recorded_at = db.Column(db.DateTime, default=datetime.utcnow)
Funcionalidades
1. Registro de Consumo
Usuário informa a quantidade de puffs (unidades) através de um formulário

Validação: valor entre 0 e 5000

Registro vinculado ao user_id logado

Registro automático da data/hora (recorded_at)

2. Visualização Histórica
Tabela com todos os registros do usuário

Colunas: Data/Hora, Quantidade de Puffs

Ações por registro: Editar e Excluir

3. Dashboard com Gráficos e Previsões
Gráfico de Barras:

Média atual (últimos 30 dias)

Previsão para 30, 90 e 120 dias

Cards de Estatísticas:

Média atual com valor numérico

Previsões com tendência (📈 subindo / 📉 descendo / ➡️ estável)

Percentual de variação em relação à média atual

Data estimada para cada previsão

Método de Cálculo das Previsões:

Regressão Linear (scikit-learn) com todos os dados históricos

Suavização de outliers (> 2000 puffs/dia)

Cálculo da média diária real: puffs / dias_desde_ultimo_registro

Modelo treinado com datas em dias desde o primeiro registro

Observações Técnicas
O módulo compartilha o mesmo Blueprint (dashboard) do sistema principal

Utiliza a mesma camada de autenticação (Flask-Login + sessão)

Não interfere nas tabelas de métricas corporais (Eu_2016)

As previsões são calculadas em tempo real a cada requisição

A lógica de previsão está diretamente na rota (não modularizada em ml/)

## 4. Análise de Implementação

### 4.1 Pontos Fortes

| Aspecto | Descrição |
|---------|-----------|
| **Feedback Visual** | Classe `active` indica filtro selecionado |
| **Fallback Inteligente** | Se um período não for reconhecido, volta para `30days` |
| **Flexibilidade** | Suporte a diferentes granularidades de tempo |
| **Separação de Responsabilidades** | Cada período tem sua própria função de configuração |

### 4.2 Pontos de Atenção

| Problema | Descrição | Sugestão |
|----------|-----------|----------|
| **Lógica em Cliente** | Cálculo de períodos no frontend | Mover para backend (API) |
| **Duplicação de Código** | `if (period === '...')` para cada período | Usar switch-case ou objeto de configuração |
| **Falta de Escopo** | Não há tratamento para "Todos os dados" | Adicionar opção "All Time" |

## 5. Sugestões de Melhoria

### 5.1 Refatoração da Função `loadChartData`

```javascript
const PERIOD_CONFIGS = {
    '7days': { label: 'Last 7 Days', options: getOptionsFor7Days },
    '30days': { label: 'Last 30 Days', options: getOptionsFor30Days },
    'current_month': { label: 'Current Month', options: getOptionsForCurrentMonth },
    'last_year': { label: 'Last Year', options: getOptionsForLastYear }
};

function loadChartData(period = '30days') {
    const config = PERIOD_CONFIGS[period];
    if (!config) {
        console.warn(`Período inválido: ${period}, usando 30days`);
        return loadChartData('30days');
    }
    
    fetch(`{{ url_for('dashboard.get_user_metrics_timeline') }}?period=${period}`)
        .then(response => response.json())
        .then(data => {
            const options = config.options(data.labels);
            updateChart(options);
        });
}
```

## 6. Análise de Integração com ML

### 6.1 Conexão com `predictor.py`

O dashboard provavelmente utiliza os dados do serviço `FitMLService` para:

1. **Exibir predições históricas** (gráfico de tendência)
2. **Mostrar métricas previstas** vs. reais
3. **Permitir filtros temporais** para análise de evolução

### 6.2 Fluxo Sugerido

```
Usuário clica no filtro (ex: "Last 30 Days")
    ↓
loadChartData('30days')
    ↓
GET /dashboard/get_user_metrics_timeline?period=30days
    ↓
Backend consulta dados do usuário (isolamento por user_id)
    ↓
Retorna JSON com labels + datasets
    ↓
Frontend atualiza gráfico
```

- [ ] Refatorar lógica de períodos para usar objeto de configuração
